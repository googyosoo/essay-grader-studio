# AI Essay Grader

고등학교 영어 수업에서 학생 영작문을 첨삭하고 루브릭 기준으로 채점하는 브라우저 전용 웹 도구입니다. Gemini API 키(BYOK)를 연결하면 AI 분석을 사용하고, 키가 없어도 내장된 규칙 기반 폴백 엔진으로 문법 교정과 채점을 실행할 수 있습니다.

## 주요 기능

- **4영역 맞춤형 루브릭**: 내용(Content), 구성(Organization), 언어(Language), 문법(Grammar) 영역의 배점을 교사가 자유롭게 수정하고 프리셋을 적용할 수 있습니다.
- **문장별 첨삭 하이라이트**: 원문을 문장 단위로 구분해 오류가 있는 문장을 강조 표시하고, 문장을 누르면 원문과 교정안, 한국어 설명을 바로 확인합니다.
- **학생용 피드백과 교사용 요약 분리**: 학생 화면에는 강점, 보완 가이드, 문장별 첨삭만 공개하며 교사용 진단 요약과 지도 포인트, 편차 경고는 교사 화면에만 유지합니다.
- **2회 채점 편차 감지**: 동일 에세이를 다시 채점해 직전 회차와 점수 차이가 크면(총점 10% 이상 또는 영역 배점 25% 이상) `교사 확인 필요` 경고를 표시합니다.
- **일괄 채점 및 CSV 내보내기**: 여러 편의 에세이를 한 번에 채점하고, 엑셀에서 한글이 깨지지 않는 UTF-8 BOM CSV 파일로 내려받을 수 있습니다.
- **수업용 익명 샘플 내장**: 처음 접속해도 개인정보나 교과서 원문 없이 가상 영어 에세이 2편(`Sample 01`, `Sample 02`)으로 전체 흐름을 테스트할 수 있습니다.

## 교사용 빠른 시작

1. 첫 화면에서 **교사용 대시보드 시작** 버튼을 누릅니다.
2. 상단 **루브릭** 버튼에서 4영역 배점을 확인하거나 수정합니다.
3. Gemini 무료 등급 API 키를 보유한 경우 **API 키 설정**에 입력합니다. (키 없이도 규칙 기반 폴백 채점이 바로 동작합니다.)
4. **개별 첨삭 및 채점** 또는 **일괄 채점 및 CSV** 탭에서 에세이를 분석하고, 학생 공개 저장 또는 CSV 다운로드를 진행합니다.

## 로컬 실행 방법

```bash
npm install
npm run dev
```

프로덕션 빌드 확인:

```bash
npm run lint
npm run build
npm run preview
```

## GitHub Pages 배포 방법

이 프로젝트는 백엔드 서버 없이 브라우저만으로 동작하며 `vite.config.js`의 `base: './'`와 `HashRouter`, `.github/workflows/deploy.yml`이 미리 구성되어 있습니다.

1. GitHub 저장소의 `Settings` → `Pages`에서 Build and deployment 소스를 **GitHub Actions**로 선택합니다.
2. `main` 브랜치에 push하면 자동으로 빌드되어 GitHub Pages에 배포됩니다.

## 보안 및 개인정보 안내

- 학생 실명 대신 익명 식별 ID(`Sample 01`, `class1_no05` 등) 사용을 권장합니다.
- 입력한 Gemini API 키와 학생 데이터는 외부 서버나 저장소에 기록되지 않고 사용자의 브라우저 `localStorage`에만 보관됩니다.
